## What every theme ships with

- **Arabic first, bilingual.** Right-to-left is the base layout, English mirrors it, and an `ع | EN` switch sits in the header and footer.
- **A designed footer**, not a list of links.
- **Motion with restraint.** Scroll reveals and parallax use transform and opacity only. Everything respects `prefers-reduced-motion`, and the layout does not shift.
- **Built on Salla's React engine** ([Twilight](https://docs.salla.dev/twilight/react)), with the merchant settings in the theme customizer.
